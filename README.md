## Programs

### 1. Basic Data Types

Demonstrates the use of basic data types such as `int`, `char`, and `float` to store student details.

### 2. if-else

Demonstrates the use of an `if-else` statement to check whether a student has passed or failed.

### 3. Loop and Array

Demonstrates the use of an array and `for` loop to store and display the marks of five students.

### 4. Functions

Demonstrates the creation and use of a function to perform addition of two numbers.

### 5. Class and Object

Demonstrates the concept of class and object by storing and displaying student details.

### 6. Constructor and Destructor

Demonstrates the automatic execution of a constructor when an object is created and a destructor when the object ends.

### 7. Static Member

Demonstrates the use of a static class member to count the number of objects created.

### 8. Inline and Friend Function

Demonstrates the use of an inline function and a friend function to access and display private data.
