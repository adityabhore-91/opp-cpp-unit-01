## About This Repository

This repository contains practical C++ programs for Unit I
of Object-Oriented Programming with C++.

The programs demonstrate basic data types, decision making,
loops, arrays, functions, classes and objects, constructors
and destructors, static members, inline functions and
friend functions.

---

# List of Programs

## 1. Basic Data Types

This program demonstrates the use of basic data types in C++.

It stores and displays a student's roll number, grade and
fee amount using `int`, `char` and `float` data types.

### Concepts Used
- int
- char
- float
- cout
- Basic input/output

---

## 2. if-else

This program checks whether a student has passed or failed
based on the marks obtained.

It demonstrates selection using the `if-else` statement.

### Concepts Used
- if statement
- else statement
- Conditional checking
- Decision making

---

## 3. Loop and Array

This program stores and displays the marks of five students.

A `for` loop is used to access and print each element of
the array.

### Concepts Used
- Array
- for loop
- Array indexing
- Iteration

---

## 4. Functions

This program creates an addition function to perform
addition of two numbers.

It demonstrates function declaration, function calling
and return values.

### Concepts Used
- Function
- Function prototype
- Function call
- Parameters
- Return value

---

## 5. Class and Object

This program stores student details using a class and object.

The `Student` class contains name and age as data members
and `show()` as a member function.

### Concepts Used
- Class
- Object
- Data members
- Member function
- Dot operator

---

## 6. Constructor and Destructor

This program demonstrates automatic object initialization
and cleanup using a constructor and destructor.

The constructor is called when the object is created and
the destructor is called when the object ends.

### Concepts Used
- Constructor
- Destructor
- Object creation
- Object destruction

---

## 7. Static Member

This program counts how many objects of a class are created.

A static data member named `count` is shared by all objects
of the `Student` class.

### Concepts Used
- Static data member
- Constructor
- Shared class data
- Scope resolution operator

---

## 8. Inline and Friend Function

This program demonstrates an inline getter function and
a friend function for accessing private data.

The `getValue()` function returns the private value, while
the friend function can directly access the private data.

### Concepts Used
- Private data
- Constructor
- Inline function
- Getter function
- Friend function
